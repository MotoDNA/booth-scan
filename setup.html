Set up the booth desk on your phone

Six short steps. About three minutes. Ask the booth manager if anything here does not match what you see.

0 / 6
Booth manager only — create the setup link

Paste your two values below. This page builds the one-tap setup link that carries both. Nothing is saved or sent anywhere; it stays in this browser tab.

Anyone holding this link can use your API key, and the usage is billed to your account. Send it in a one-to-one message only, delete the message afterwards, and delete the key when the show ends.

Open the setup link the manager sent you

Tap it once. The recognition key and the shared sheet connection are applied automatically. You will see a short confirmation at the bottom of the screen.

Open it in Safari or Chrome. If it opens inside a messaging app, tap the menu and choose “Open in browser”.

Add the app to your home screen

This keeps your records safe between sessions and removes the browser bars.

iPhone: Share button → Add to Home Screen. Android: menu (⋮) → Add to Home screen. Huawei: menu → Add to desktop.

Launch it from the home screen icon

Always start the app from this icon, not from a browser tab. Check the version tag next to the title at the top.

It should read v1.7.3. If it shows an older number, delete the icon and add it again.

Enter your own name

Settings → Staff name → type your name → Save. Every visitor you record is tagged with it, so the team can tell who spoke to whom.

Use the same spelling all four days. Two spellings become two people in the report.

Check that sharing is live

Settings → Live sharing → Check connection. A green line confirms it. Then open the List tab: you should see your name under “Online now”.

If your name is missing there, your phone is not sending to the sheet. Tell the booth manager before the doors open.

Record one test visitor

Photograph any business card, or use “Type manually”. Save it, then confirm the entry appears on the shared sheet. Delete it afterwards.

Do this before the first visitor arrives, not during the rush.

Every evening, before you leave

  • Export CSV and Save all photos, then send both files to your own email.
  • Photos live only on your phone. The shared sheet holds text, never images.
  • Charge the phone and the power bank overnight. Recognition uses more battery than usual.

If something goes wrong

Recognition does not fill anything in Open the setup link again. The key may not have been applied. You can still type everything by hand and the record is just as valid.
The counter shows “Queued” Nothing is lost. The phone saved it and will upload as soon as the connection returns. Hall Wi-Fi drops often; keep recording.
A card was cropped badly Tap “View original” on the capture screen to see the untouched photo, or turn off Auto edge crop in Settings.
Records are missing from the sheet Settings → Re-send the whole list to the sheet. Existing rows are overwritten, not duplicated, so it is always safe to press.
